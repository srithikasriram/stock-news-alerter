# stock-news-alerter

Features
- Uses stock name and company name as input.
- Checks the difference between company's past two days' stock using Alpha Vantage API
- If the difference is larger than 5%, then news channel API is used to find top 3 headlines regarding company.
- An email with the top three headlines is sent to user.

Technologies
- Python
- Libraries: Requests, SMTPlib
